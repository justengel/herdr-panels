## 0.1.0 - 2026-10-27

First public release. The program is a desk for a running Herdr session: live panes, notes, browsers, HTML, files, and installed views.

Download the archive for Linux x64, Windows x64, or macOS Apple Silicon from GitHub Releases. The program includes the page and the example files, so running it does not require Node, Rust, or this repository.
